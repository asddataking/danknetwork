# PWA Icons

This directory should contain PWA icons for the Dank Network app.

Required icons:
- `icon-192x192.png` - 192x192 pixels
- `icon-512x512.png` - 512x512 pixels

You can generate these icons from a square logo/design. The icons should:
- Have a transparent or dark background
- Feature the Dank Network branding (DN logo or text)
- Be optimized for web use

For now, placeholder icons can be used, but proper icons should be added before production deployment.
